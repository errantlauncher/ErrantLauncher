Увага

Бета-версія. Це передрелізна збірка програми. Можливі помилки та зміни. Будь ласка, повідомляйте про проблеми сюди — це допоможе швидше випустити стабільну версію.

Примітка

Завантажується один exe — без інсталятора, без архіву. Один файл: Windows x64 (64-біт).

Вимоги

  • Windows 10 або 11, 64-біт (x64).
  • Папка з правом запису — програма зберігає дані поруч із exe. Уникайте Program Files та інших захищених місць, якщо не запускаєте від імені адміністратора.
  • Близько 50 МБ під exe плюс трохи місця під дані.
  • Під час першого запуску Windows SmartScreen може попередити про невідомого видавця — натисніть «Докладніше» → «Виконати в будь-якому разі». Для впевненості звірте хеш SHA-256 вище (як перевірити: FAQ).

Перший запуск

  1. Покладіть exe у папку з правом запису — підійде флешка.
  2. Запустіть його. Поруч з'явиться папка даних ErrantLauncher\.
  3. Додайте картки — перетягніть файли на вікно або скористайтеся Редактором. Готово.
