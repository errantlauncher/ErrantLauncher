Atenção

Versão beta. Esta é uma compilação de pré-lançamento do aplicativo. Erros e mudanças são possíveis. Por favor, relate problemas aqui — isso ajuda a lançar a versão estável mais rápido.

[!NOTE] Você baixa um único exe — sem instalador, sem arquivo compactado. Um arquivo: Windows x64 (64 bits).

Requisitos

  • Windows 10 ou 11, 64 bits (x64).
  • Uma pasta com permissão de gravação — o app guarda seus dados junto ao exe. Evite Program Files e outros locais protegidos, a menos que execute como administrador.
  • Cerca de 50 MB para o exe mais um pouco de espaço para os dados.
  • Na primeira execução, o Windows SmartScreen pode avisar sobre um editor desconhecido — clique em «Mais informações» → «Executar assim mesmo». Para ter certeza, compare o hash SHA-256 acima (como verificar: FAQ).

Primeira execução

  1. Coloque o exe em uma pasta com permissão de gravação — um pen drive serve.
  2. Execute-o. Uma pasta de dados ErrantLauncher\ aparece ao lado.
  3. Adicione cartões — arraste arquivos para a janela ou use o Editor. Pronto.
