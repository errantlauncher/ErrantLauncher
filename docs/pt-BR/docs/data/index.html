Dados, backups e portabilidade

O Errant Launcher é um programa portátil: todos os seus dados ficam em uma única pasta ao lado do executável. Este documento explica onde cada coisa é armazenada, como fazer backups e como transportar a coleção entre computadores.

Onde os dados são armazenados

Na primeira execução o programa cria a pasta ErrantLauncher ao lado do exe — por exemplo, se o programa está em D:\Tools\, os dados ficarão em D:\Tools\ErrantLauncher\.

O programa não escreve nada no registro do Windows nem nas pastas do perfil do usuário (Documents, AppData etc.). Toda a coleção, configurações e arquivos de serviço ficam somente dentro dessa pasta.

Conteúdo da pasta de dados

Caminho Conteúdo
ErrantLauncher\sections\*.json Seções, categorias e cartões — um arquivo por seção
ErrantLauncher\settings.json Configurações de aparência e comportamento: tema, idioma, bandeja etc.
ErrantLauncher\state.json Estado da janela, última seção aberta, contadores de execuções
ErrantLauncher\custom-icons\ Ícones adicionados por você ou extraídos de programas
ErrantLauncher\logs\ Registros locais de diagnóstico (app.log, bootstrap.log)
ErrantLauncher\.backup\ Backups automáticos dos arquivos de dados
ErrantLauncher\.mass-import-backups\ Cópias criadas antes da importação em massa

As pastas .backup, .mass-import-backups e a de serviço .import-staging são diretórios ocultos de serviço; não é preciso excluí-los manualmente, mas também não convém mexer no conteúdo deles sem necessidade.

Backup

O programa ajuda de duas formas:

  1. Exportar configuração — função integrada («Configurações» → «Exportar configuração»): - Backup completo — tudo: seções, ícones, configurações e estado; nome de arquivo sugerido — ErrantLauncher-Backup.zip; - Compartilhar coleção — seções e ícones selecionados, com marcas de favoritos, mas sem configurações; nome sugerido — ErrantLauncher-Collection.zip.
  2. Copiar a pasta manualmente — com o programa fechado, copie a pasta ErrantLauncher inteira para um local seguro. É um retrato completo dos seus dados.

Além disso, o próprio programa cria cópias em .backup\ durante operações com dados e em .mass-import-backups\ antes da importação em massa — mas isso é um seguro contra falhas, não um substituto de backups regulares.

Dica

Antes de grandes mudanças (importação em massa, mudança, atualização) faça um «Backup completo» via exportação — é o mais fácil de restaurar.

Transferência para outro computador

Método 1 — transferir tudo:

  1. Feche o programa.
  2. Copie o exe e a pasta ErrantLauncher para o novo computador ou unidade — juntos, mantendo a posição relativa.
  3. Execute o exe no novo local.

Método 2 — transportar apenas a coleção: use «Exportar configuração» no modo «Compartilhar coleção» → «Importar configuração» em outra cópia do programa (aceita .zip, .json e uma pasta de configuração).

Nota

Sobre caminhos: cartões que referenciam arquivos por letra de unidade (D:\Tools\app.exe) funcionam no novo computador apenas se os arquivos existirem lá nos mesmos caminhos. O assistente de importação em massa avisa sobre esses cartões. Os próprios dados do launcher não memorizam letras de unidade — a pasta de dados é procurada ao lado do exe.

Atualização sem perda de dados

Não há atualização automática, mas atualizar não toca nos dados:

  1. Feche o programa.
  2. Substitua ErrantLauncher-x64.exe pela nova versão.
  3. Execute. A pasta ErrantLauncher permanece no lugar — todos os cartões e configurações são preservados.

Antes de reinstalar ou desinstalar

  • Guardar: a pasta ErrantLauncher inteira (ou pelo menos sections\, settings.json e custom-icons\ se os registros não forem necessários).
  • Desinstalar: exclua o exe e a pasta ErrantLauncher. O programa não deixa outros rastros no sistema. Adicionalmente você pode excluir os diretórios temporários %TEMP%\.net\ErrantLauncher — são criados a cada execução e não são limpos automaticamente.
  • A função «Excluir todos os dados» nas configurações apaga o conteúdo da pasta de dados após duas confirmações — use-a apenas se não precisar de backup.

Se os arquivos não estiverem disponíveis

O programa distingue as situações e se comporta de forma previsível:

Situação Comportamento
Pasta de dados somente leitura Modo «Somente leitura»: os cartões ficam visíveis e executáveis, as alterações são rejeitadas com aviso e não se perdem silenciosamente
Mídia temporariamente indisponível Indicador «Sem mídia»; as alterações ficam em memória e serão salvas após a reconexão
Pasta de dados totalmente ilegível Mensagem de armazenamento indisponível; o aplicativo se encerra
Arquivo de dados individual corrompido Diálogo «Arquivo corrompido»: o arquivo é ignorado e não modificado; pode ser excluído ou mantido
Arquivo criado por versão mais nova O arquivo é lido, mas não sobrescrito — recomenda-se atualizar o programa
Vários arquivos da mesma seção O conteúdo é mesclado automaticamente, uma notificação é exibida

Restauração a partir de backup

De um arquivo exportado: «Configurações» → «Importar configuração» → escolha o arquivo → marque as seções, configurações, ícones e favoritos necessários → «Importar».

De uma cópia da pasta: com o programa fechado, substitua o conteúdo da pasta ErrantLauncher pelo conteúdo do backup.

Após falha de importação em massa: o programa informa o caminho da cópia criada antes da importação (em .mass-import-backups\) — siga a dica na mensagem de erro: copie o conteúdo dela sobre a pasta de dados ou repita a importação.

Particularidades de unidades USB

  • A execução a partir de USB é totalmente suportada — é um cenário padrão.
  • Remover a unidade durante o funcionamento pode encerrar o processo: feche sempre o programa antes de remover.
  • Se a unidade se desconectar e reconectar, o programa detectará o retorno e continuará salvando dados.
  • Em mídias protegidas contra gravação funciona o modo «Somente leitura».
  • Não há garantia absoluta de portabilidade dos cartões: se eles referenciam arquivos locais de outro computador, verifique os status dos cartões após o transporte («Arquivo ausente», «Mídia ausente»).
