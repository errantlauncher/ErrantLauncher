Requisitos de sistema e compatibilidade

O Errant Launcher é um programa portátil: precisa apenas de uma edição adequada do Windows e um pouco de espaço livre. Abaixo estão separados os requisitos confirmados, as recomendações e as limitações conhecidas da versão beta atual.

Requisitos mínimos

Parâmetro Requisito
Sistema operacional Windows 10 versão 1607 ou mais recente
Arquitetura 64 bits (x64)
.NET Não necessário — o runtime está embutido no arquivo do programa
Instalação Não necessária — um único executável
Permissões de administrador Não necessárias para executar e usar

Não suportados:

  • Windows 7, 8 e 8.1 (limitação da plataforma .NET 8 utilizada);
  • edições de 32 bits do Windows — não há build x86;
  • processadores ARM64 — não há build dedicada; em dispositivos ARM64 execute a versão x64 através da emulação padrão do Windows.

Instalação e execução

Não há instalador — o programa é distribuído como um único arquivo ErrantLauncher-x64.exe.

  1. Copie o arquivo para qualquer pasta: Documentos, um diretório separado no disco ou uma unidade USB.
  2. Execute-o com um duplo clique.
  3. Na primeira execução é criada a pasta ErrantLauncher ao lado do arquivo do programa — nela ficam todos os cartões, configurações e dados de serviço.
Atenção

Aviso do SmartScreen. O executável não é assinado digitalmente, por isso o Windows pode exibir um aviso — é o esperado para uma versão beta. Como verificar a autenticidade do arquivo: FAQ.

Requisitos de tela

As janelas do programa têm tamanho fixo — não podem ser alteradas:

  • conteúdo da janela: 1000 × 620 DIP;
  • tamanho externo da janela incluindo a sombra decorativa: 1028 × 648 DIP.

DIP são unidades lógicas de tamanho de interface, não pixels físicos da tela. O tamanho real da janela em pixels depende da escala do Windows (por exemplo, com escala de 150% a janela ocupará cerca de 1540 × 970 pixels físicos).

Para exibir a interface completa, a área de trabalho da tela (a tela sem a barra de tarefas) deve comportar a janela inteira. Valores altos de escala reduzem a área de trabalho em unidades lógicas e podem exigir uma resolução de tela maior.

Se a área de trabalho for menor que o tamanho da janela, ao ser centralizada parte dela pode ficar fora das bordas da tela, incluindo a barra superior com os botões de minimizar e fechar.

Dica

Na prática: em desktops típicos (1920 × 1080 ou mais) com escala de 100–150% a janela cabe completamente. Em telas de baixa resolução com escala alta (por exemplo, 1366 × 768 a 125–150%) a área de trabalho pode não ser suficiente — verifique a exibição na sua tela na primeira execução.

Disco e permissões de acesso

  • Localização. O programa deve estar em uma pasta da qual a leitura seja permitida; para salvar dados também é necessária a gravação.
  • Gravação. Se a pasta ErrantLauncher estiver disponível apenas para leitura, o programa abrirá em modo somente leitura: os cartões podem ser visualizados e executados, mas as alterações não são salvas — uma notificação clara é exibida sobre isso.
  • Registro e perfil. O programa não escreve nada no registro do Windows nem nas pastas do perfil do usuário — todos os dados vivem somente em ErrantLauncher\ ao lado do exe.
  • Pasta temporária. A cada execução o aplicativo de arquivo único descompacta suas bibliotecas em %TEMP%\.net\ErrantLauncher. Esses diretórios se acumulam e não são limpos automaticamente; podem ser excluídos manualmente com o programa fechado.

Execução a partir de unidade USB

O programa foi projetado para executar a partir de mídias removíveis:

  • todo o conjunto — o exe e a pasta ErrantLauncher — é transportado como está;
  • a letra da unidade pode mudar entre computadores: os dados são procurados ao lado do executável, não por um caminho absoluto.

Limitações:

  • remover a unidade USB durante o funcionamento pode encerrar o processo — feche o programa antes de removê-la;
  • se a unidade ficar temporariamente indisponível, o programa informa «Sem mídia» e mantém as alterações em memória até a reconexão;
  • cartões que referenciam arquivos por letra de unidade (por exemplo, D:\Tools\app.exe) podem não abrir em um computador onde essa letra não existe.

Limitações de compatibilidade conhecidas

  • Somente Windows; não há versões para macOS e Linux.
  • Somente x64; não há builds x86 nem ARM64.
  • O executável não é assinado — espere o aviso do SmartScreen.
