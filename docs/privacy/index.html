Privacy and Data Handling

At a Glance

  • All data is stored locally in the ErrantLauncher folder next to the executable.
  • No telemetry. The launcher does not send usage statistics, diagnostic information, or automatic error reports to the developer.
  • The launcher does not contact the developer's servers on its own to check for updates, perform analytics, or activate the software.
  • Network activity may occur when you choose to open links, launch programs, or run commands you have added to cards.
  • No account, registration, or internet connection is required to use the launcher.

What Data Does the App Create?

The launcher stores its data locally in the ErrantLauncher folder next to the executable. This includes sections, categories and cards, settings, window state, custom icons, local logs, and internal backups.

For a detailed breakdown of the folder contents, see Data, backups and portability.

This data stays on your computer or on the storage device where the launcher is located. The app does not write to the Windows Registry or your user profile.

What Is Sent to the Developer?

The launcher itself sends nothing to the developer. It has no telemetry, analytics, automatic error reporting, network-based update checks, or usage statistics collection.

The developer receives information only if you choose to send it voluntarily when contacting support — for example, a message describing a problem or an attached log file.

For guidance on what to include in a support request and what you should avoid sharing, see Support and error reports.

Network Activity

The Launcher Itself

The launcher does not contact the developer's servers or check for updates over the network. Websites are opened only when you choose to follow a link, such as:

  • URL / URI cards;
  • links in the About window, including the website, documentation, bug-report page, GitHub releases, and project support page.

When you open a link, Windows launches your default browser or another application associated with that type of address. Any subsequent interaction with the website is governed by the website's and the application's own policies, not by the launcher.

Through User-Configured Cards

The launcher also lets you run programs and commands that you add to cards yourself. These may perform network operations:

  • A launched program may connect to the internet according to its own features and settings.
  • Command cards run the commands you specify, including commands that access network resources.
  • During bulk import, you can enable a filter to scan network paths (UNC). In that case, the launcher reads data from the network locations you selected.

Therefore, no telemetry does not mean no network activity at all. Network activity may occur when you open links, launch programs, run your own commands, or access selected network locations.

Logs

Local logs are stored in ErrantLauncher\logs\. They may contain technical information such as error messages, paths to data files, and configuration file names.

The launcher does not automatically send logs to the developer. If you choose to attach a log to a support request, review it first and remove any information you do not want to share, such as file paths containing your folder names.

Imported Files

When you use the Import feature, the launcher warns you that it has not verified the imported file for safety. Such files may contain commands and links.

Only import configurations from sources you trust, and review their contents before using them.

Deleting Your Data

  • Deleting the ErrantLauncher folder removes the launcher's local data stored in that folder, including cards, settings, icons, logs, and backups. The launcher does not send this data to the developer's servers or create cloud backups of it.
  • The "Delete All Data" option in Settings removes local data from within the app. You must confirm the action twice before the data is deleted.
  • .NET temporary files. The launcher is built using Native AOT, so .NET components are not extracted to %TEMP%\.net\ErrantLauncher at startup. If files from older versions remain in that location, you can delete them manually after closing the app.
