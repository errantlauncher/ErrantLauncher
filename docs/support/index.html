Report a Problem

This page explains how to report a bug in Errant Launcher and how to describe a problem so it is easier to reproduce, investigate, and fix.

Report a Bug

Found a bug or have a suggestion for improvement? Open an issue on GitHub:

Open GitHub Issues

Before submitting an issue, check the FAQ and Troubleshooting sections. They already cover many common questions, including SmartScreen warnings, read-only mode, card statuses, and window sizing.

How to Describe a Bug

A good bug report answers three questions:

  1. What were you doing? List the steps in order. For example: "Opened the Editor → Bulk Import → selected the D:\Tools folder → clicked 'Scan'."
  2. What did you expect to happen? For example: "A list of candidates should have appeared."
  3. What actually happened? For example: "The app closed" or "An error message appeared." Include the exact wording of the message or attach a screenshot.

What to Include in Your Report

InformationWhere to find it
App versionThe About window, for example, 1.0.0-beta.2
Windows version and architecturePress Win + R and enter winver. Find the system architecture under Settings → System → About
Display scalingSettings → System → Display → Scale, if the problem involves how the app is displayed
Where the app is running fromThe path to the executable and the storage location: a local drive or USB drive
LogsErrantLauncher\logs\app.log and ErrantLauncher\logs\bootstrap.log. The ErrantLauncher folder is located next to the executable
Steps to reproduceThe sequence of actions that leads to the problem
Error messageThe full message text or a screenshot

Before attaching a log, open it in Notepad and review its contents. Logs may contain paths to your files and folders. Remove or redact any information you do not want to share.

What Not to Send

  • Passwords, keys, or tokens. The app does not store or request them, but they could accidentally appear in copied text or screenshots.
  • Full card contents containing personal information. Share only the relevant parts of file paths, commands, or links needed to understand the problem.
  • The entire ErrantLauncher folder unless necessary. If configuration files are needed to investigate a bug, attach only the relevant files and check them for personal information before sharing.

What to Expect

Errant Launcher is a free, independent software project currently in beta testing. There are no fixed timelines for bug fixes or new releases. Fixes depend on the nature of the issue and the developer's available time and resources, so not every report will necessarily result in a change to the application.

If you find a bug or want to suggest an improvement, please open an issue on GitHub. A detailed description of the problem helps identify its cause.

Follow the Releases page to stay informed about new versions and available fixes.
