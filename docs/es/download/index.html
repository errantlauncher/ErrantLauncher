Atención

Versión beta. Esta es una compilación previa al lanzamiento de la aplicación. Puede haber errores y cambios. Por favor, informa de los problemas aquí — nos ayuda a lanzar la versión estable antes.

[!NOTE] Descargas un único exe — sin instalador, sin archivo comprimido. Un archivo: Windows x64 (64 bits).

Requisitos

  • Windows 10 u 11, 64 bits (x64).
  • Una carpeta con permiso de escritura — la app guarda sus datos junto al exe. Evita Program Files y otras ubicaciones protegidas a menos que la ejecutes como administrador.
  • Unos 50 MB para el exe más algo de espacio para los datos.
  • En el primer inicio, Windows SmartScreen puede avisar sobre un editor desconocido — haz clic en «Más información» → «Ejecutar de todas formas». Para estar seguro, compara el hash SHA-256 de arriba (cómo comprobarlo: FAQ).

Primer inicio

  1. Coloca el exe en una carpeta con permiso de escritura — una unidad flash también sirve.
  2. Ejecútalo. Aparece una carpeta de datos ErrantLauncher\ junto a él.
  3. Agrega tarjetas — arrastra archivos a la ventana o usa el Editor. Listo.
