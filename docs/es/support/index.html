Soporte e informes de errores

Dónde hacer preguntas sobre Errant Launcher y cómo redactar un informe de error para que el problema se encuentre y se resuelva rápido.

Canales de soporte

Canales oficiales del proyecto (los mismos enlaces están dentro de la app — ventana «Acerca de»; los canales funcionan desde la publicación del lanzamiento):

Canal Dirección
Documentación Documentación en el sitio
Informar de un error GitHub Issues
Lanzamientos GitHub Releases

Antes de escribir, echa un vistazo a las FAQ y solución de problemas — muchas preguntas (SmartScreen, «Solo lectura», estados de tarjetas, tamaño de ventana) ya están respondidas ahí.

Cómo describir un error

Un buen informe responde a tres preguntas:

  1. Qué hacías — pasos de reproducción, en orden. Por ejemplo: «abrí el Editor → Importación masiva → elegí la carpeta D:\Tools → pulsé "Escanear"».
  2. Qué esperabas — «debía aparecer una lista de candidatos».
  3. Qué pasó — «la app se cerró» / «apareció un mensaje …» — cita el texto del mensaje literalmente o adjunta una captura.

Qué adjuntar al informe

Información Dónde encontrarla
Versión de la app Ventana «Acerca de» (p. ej. 1.0.0-beta.1)
Versión y arquitectura de Windows Win+R → winver; arquitectura — en «Configuración → Sistema → Acerca de»
Escala de pantalla Configuración → Sistema → Pantalla → Escala (si el problema es de visualización)
Desde dónde se ejecuta la app Ruta del exe; disco local o USB
Registros ErrantLauncher\logs\app.log y bootstrap.log — la carpeta ErrantLauncher está junto al exe
Pasos de reproducción Ver arriba — cuanto más precisos, mejor
Texto del mensaje de error Literalmente o una captura

Antes de enviar un registro, ábrelo en el Bloc de notas y revisa el contenido: los registros pueden contener rutas a tus archivos y carpetas — quita lo que no quieras revelar.

Qué NO enviar

  • Contraseñas, claves, tokens — la app ni los guarda ni los pide, pero pueden colarse accidentalmente en un texto copiado o una captura.
  • El contenido completo de tus tarjetas si contiene datos personales: rutas, comandos, enlaces — envía solo los fragmentos relacionados con el problema.
  • La carpeta ErrantLauncher entera si no te la han pedido: exporta la configuración solo a petición del soporte y solo tras revisar su contenido.

Qué esperar

Este es un proyecto independiente y gratuito en fase beta: no hay promesas sobre tiempos de respuesta, pero cada informe bien descrito ayuda a lanzar la versión estable antes. Vigila la página de lanzamientos — las correcciones llegan en las nuevas versiones.
