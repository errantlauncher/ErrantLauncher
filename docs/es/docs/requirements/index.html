Requisitos del sistema y compatibilidad

Errant Launcher es un programa portátil: solo necesita una edición de Windows adecuada y algo de espacio libre. A continuación se separan los requisitos confirmados, las recomendaciones y las limitaciones conocidas de la versión beta actual.

Requisitos mínimos

Parámetro Requisito
Sistema operativo Windows 10 versión 1607 o posterior
Arquitectura 64 bits (x64)
.NET No necesario — el entorno de ejecución está integrado en el archivo del programa
Instalación No necesaria — un único ejecutable
Permisos de administrador No necesarios para ejecutar ni trabajar

No compatibles:

  • Windows 7, 8 y 8.1 (limitación de la plataforma .NET 8 utilizada);
  • ediciones de Windows de 32 bits — no se distribuye compilación x86;
  • procesadores ARM64 — no hay compilación dedicada; en dispositivos ARM64 ejecuta la versión x64 mediante la emulación estándar de Windows.

Instalación e inicio

No hay instalador — el programa se distribuye como un único archivo ErrantLauncher-x64.exe.

  1. Copia el archivo a cualquier carpeta: Documentos, un directorio propio en el disco o una unidad USB.
  2. Ejecútalo con doble clic.
  3. En el primer inicio se crea la carpeta ErrantLauncher junto al archivo del programa — ahí se guardan todas las tarjetas, la configuración y los datos de servicio.
Atención

Aviso de SmartScreen. El ejecutable no está firmado digitalmente, por lo que Windows puede mostrar una advertencia — es lo esperado para una versión beta. Cómo verificar la autenticidad del archivo: FAQ.

Requisitos de pantalla

Las ventanas del programa tienen tamaño fijo — no se puede cambiar:

  • contenido de la ventana: 1000 × 620 DIP;
  • tamaño exterior de la ventana incluida la sombra decorativa: 1028 × 648 DIP.

DIP son unidades lógicas de tamaño de interfaz, no píxeles físicos de la pantalla. El tamaño real de la ventana en píxeles depende de la escala de Windows (por ejemplo, con escala del 150 % la ventana ocupará unos 1540 × 970 píxeles físicos).

Para mostrar la interfaz completa, el área de trabajo de la pantalla (la pantalla sin la barra de tareas) debe contener la ventana entera. Los valores altos de escala reducen el área de trabajo en unidades lógicas y pueden requerir una resolución de pantalla mayor.

Si el área de trabajo es menor que el tamaño de la ventana, al centrarse una parte puede quedar fuera de los bordes de la pantalla, incluida la barra superior con los botones de minimizar y cerrar.

Consejo

En la práctica: en escritorios típicos (1920 × 1080 o más) con escala del 100–150 % la ventana cabe por completo. En pantallas de baja resolución con escala alta (por ejemplo, 1366 × 768 al 125–150 %) el área de trabajo puede quedarse corta — comprueba la visualización en tu pantalla en el primer inicio.

Disco y permisos de acceso

  • Ubicación. El programa debe estar en una carpeta desde la que se permita la lectura; para guardar datos también hace falta escritura.
  • Escritura. Si la carpeta ErrantLauncher es de solo lectura, el programa se abrirá en modo de solo lectura: las tarjetas se pueden ver y ejecutar, pero los cambios no se guardan — se muestra una notificación clara al respecto.
  • Registro y perfil. El programa no escribe nada en el registro de Windows ni en las carpetas del perfil de usuario — todos los datos viven únicamente en ErrantLauncher\ junto al exe.
  • Carpeta temporal. En cada inicio la aplicación de un solo archivo desempaqueta sus bibliotecas en %TEMP%\.net\ErrantLauncher. Estos directorios se acumulan y no se limpian automáticamente; se pueden borrar manualmente con el programa cerrado.

Ejecución desde una unidad USB

El programa está diseñado para funcionar desde medios extraíbles:

  • todo el conjunto — el exe y la carpeta ErrantLauncher — se traslada tal cual;
  • la letra de la unidad puede cambiar entre equipos: los datos se buscan junto al ejecutable, no por una ruta absoluta.

Limitaciones:

  • extraer la unidad USB durante el trabajo puede terminar el proceso — cierra el programa antes de extraerla;
  • si la unidad no está disponible temporalmente, el programa informa «Sin medio» y conserva los cambios en memoria hasta su reconexión;
  • las tarjetas que referencian archivos por letra de unidad (por ejemplo, D:\Tools\app.exe) pueden no abrirse en un equipo donde esa letra no existe.

Limitaciones de compatibilidad conocidas

  • Solo Windows; no hay versiones para macOS ni Linux.
  • Solo x64; no hay compilaciones x86 ni ARM64.
  • El ejecutable no está firmado — espera el aviso de SmartScreen.
