System Requirements and Compatibility

Errant Launcher is a portable Windows application. No installation is required: download the ZIP archive, extract it, and launch the application.

Minimum Requirements

ComponentRequirement
Operating systemWindows 10 version 1607 or later
Architecture64-bit (x64)
.NETNo separate installation required — the runtime is built into the application using Native AOT
InstallationNot required — the application runs directly from its extracted folder
Free disk spaceSufficient space for the application, its required libraries, and user data

Not supported:

  • Windows 7, Windows 8, and Windows 8.1
  • 32-bit versions of Windows
  • Native ARM64 builds are not available

On ARM64 devices running Windows with x64 emulation support, the x64 version of Errant Launcher may run through emulation.

Display Requirements

The application window has a fixed size and cannot be resized.

The window's physical pixel dimensions depend on your screen resolution and Windows display scaling. At higher scaling levels, the window occupies more physical pixels, so it may not fit entirely within the available screen area on lower-resolution displays.

On typical desktop systems with a resolution of 1920 × 1080 and display scaling set to 100–150%, the window will generally fit on screen. At lower resolutions and higher scaling levels, such as 1366 × 768 at 150%, part of the window may extend beyond the visible desktop area.

Check how the window appears on your display when launching the application for the first time, especially if you use a lower resolution or increased display scaling.
