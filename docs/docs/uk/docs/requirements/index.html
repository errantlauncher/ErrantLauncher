Системні вимоги та сумісність

Errant Launcher — переносна програма: їй потрібен лише відповідний випуск Windows і трохи вільного місця. Нижче розділено підтверджені вимоги, рекомендації та відомі обмеження поточної бета-версії.

Мінімальні вимоги

Параметр Вимога
Операційна система Windows 10 версії 1607 або новіша
Архітектура 64-розрядна (x64)
.NET Не потрібен — середовище виконання вбудовано у файл програми
Встановлення Не потрібне — один виконуваний файл
Права адміністратора Не потрібні для запуску та роботи

Не підтримуються:

  • Windows 7, 8 та 8.1 (обмеження використовуваної платформи .NET 8);
  • 32-розрядні випуски Windows — збірки x86 не постачається;
  • процесори ARM64 — окремої збірки немає; на ARM64-пристроях запускайте x64-версію через штатну емуляцію Windows.

Встановлення та запуск

Інсталятора немає — програма постачається одним файлом ErrantLauncher-x64.exe.

  1. Скопіюйте файл у будь-яку папку: Документи, окремий каталог на диску або USB-накопичувач.
  2. Запустіть його подвійним клацанням.
  3. Під час першого запуску поруч із файлом програми створюється папка ErrantLauncher — у ній зберігаються всі картки, налаштування та службові дані.
Увага

Попередження SmartScreen. Виконуваний файл не підписаний цифровим підписом, тому Windows може показати попередження — це очікувано для бета-версії. Як перевірити справжність файлу: FAQ.

Вимоги до екрана

Вікна програми мають фіксований розмір — змінити його не можна:

  • вміст вікна: 1000 × 620 DIP;
  • зовнішній габарит вікна з урахуванням декоративної тіні: 1028 × 648 DIP.

DIP — це логічні одиниці розміру інтерфейсу, а не фізичні пікселі екрана. Фактичний розмір вікна в пікселях залежить від масштабу Windows (наприклад, за масштабу 150 % вікно займе приблизно 1540 × 970 фізичних пікселів).

Для повного відображення інтерфейсу робоча область екрана (екран без панелі завдань) повинна вміщати вікно цілком. Високі значення масштабу зменшують робочу область у логічних одиницях і можуть вимагати вищої роздільної здатності екрана.

Якщо робоча область менша за габарит вікна, частина вікна під час центрування може опинитися за краями екрана, включно з верхньою панеллю з кнопками згортання та закриття.

Порада

На практиці: на типових десктопах (1920 × 1080 і вище) за масштабу 100–150 % вікно вміщується повністю. На екранах із низькою роздільною здатністю та високим масштабом (наприклад, 1366 × 768 за 125–150 %) робочої області може не вистачити — перевірте відображення на своєму екрані під час першого запуску.

Диск і права доступу

  • Розташування. Програма має лежати в папці, з якої дозволене читання; для збереження даних потрібна і можливість запису.
  • Запис. Якщо папка ErrantLauncher доступна лише для читання, програма відкриється в режимі лише читання: картки можна переглядати й запускати, але зміни не зберігаються — про це виводиться зрозуміле сповіщення.
  • Реєстр і профіль. Програма нічого не пише в реєстр Windows і в папки профілю користувача — усі дані живуть лише в ErrantLauncher\ поруч із exe-файлом.
  • Тимчасова папка. Під час кожного запуску однофайлова програма розпаковує свої бібліотеки в %TEMP%\.net\ErrantLauncher. Ці каталоги накопичуються й не очищаються автоматично; їх можна безпечно видалити вручну, доки програма закрита.

Запуск із USB-накопичувача

Програма розрахована на запуск зі знімних носіїв:

  • увесь комплект — exe-файл і папка ErrantLauncher — переноситься як є;
  • літера диска може змінюватися між комп'ютерами: дані шукаються поруч із виконуваним файлом, а не за абсолютним шляхом.

Обмеження:

  • вилучення USB-носія під час роботи може завершити процес — закривайте програму перед вилученням;
  • якщо накопичувач тимчасово недоступний, програма повідомляє «Немає носія» і зберігає зміни в пам'яті до його повторного підключення;
  • картки, що посилаються на файли з літерою диска (наприклад, D:\Tools\app.exe), можуть не відкритися на комп'ютері, де цієї літери немає.

Відомі обмеження сумісності

  • Лише Windows; версій для macOS та Linux немає.
  • Лише x64; збірок x86 та ARM64 немає.
  • Виконуваний файл не підписаний — очікуйте попередження SmartScreen.
