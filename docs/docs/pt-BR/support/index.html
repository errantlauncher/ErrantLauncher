Como descrever um erro

Um bom relato responde a três perguntas:

  1. O que você estava fazendo — passos para reproduzir, em ordem. Por exemplo: «abri o Editor → Importação em massa → escolhi a pasta D:\Tools → cliquei em "Verificar"».
  2. O que esperava — «uma lista de candidatos deveria aparecer».
  3. O que aconteceu — «o aplicativo fechou» / «uma mensagem apareceu …» — cite o texto da mensagem literalmente ou anexe uma captura de tela.

O que anexar ao relato

Informação Onde encontrar
Versão do aplicativo Janela «Sobre» (ex.: 1.0.0-beta.1)
Versão e arquitetura do Windows Win+R → winver; arquitetura — em «Configurações → Sistema → Sobre»
Escala da tela Configurações → Sistema → Tela → Escala (se o problema for de exibição)
De onde o app é executado Caminho do exe; disco local ou USB
Registros ErrantLauncher\logs\app.log e bootstrap.log — a pasta ErrantLauncher fica ao lado do exe
Passos para reproduzir Veja acima — quanto mais precisos, melhor
Texto da mensagem de erro Literalmente ou captura de tela

Antes de enviar um registro, abra-o no Bloco de Notas e revise o conteúdo: os registros podem conter caminhos dos seus arquivos e pastas — remova o que não quiser revelar.

O que NÃO enviar

  • Senhas, chaves, tokens — o app não os guarda nem os pede, mas eles podem parar acidentalmente num texto copiado ou numa captura.
  • O conteúdo completo dos seus cartões se contiver dados pessoais: caminhos, comandos, links — envie apenas os fragmentos relacionados ao problema.
  • A pasta ErrantLauncher inteira, a menos que peçam: exporte a configuração apenas a pedido do suporte e apenas depois de verificar o conteúdo.

O que esperar

Este é um projeto independente e gratuito em fase beta: não há promessas sobre prazos de resposta, mas cada relato bem descrito ajuda a lançar a versão estável mais rápido. Acompanhe a página de lançamentos — as correções chegam nas novas versões.
