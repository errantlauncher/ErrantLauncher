Системные требования и совместимость

Errant Launcher — переносная программа: ей нужен только подходящий выпуск Windows и немного свободного места. Ниже разделены подтверждённые требования, рекомендации и известные ограничения текущей бета-версии.

Минимальные требования

Параметр Требование
Операционная система Windows 10 версии 1607 или новее
Архитектура 64-разрядная (x64)
.NET Не требуется — среда выполнения встроена в файл программы
Установка Не требуется — один исполняемый файл
Права администратора Не требуются для запуска и работы

Не поддерживаются:

  • Windows 7, 8 и 8.1 (ограничение используемой платформы .NET 8);
  • 32-разрядные выпуски Windows — сборки x86 не поставляется;
  • процессоры ARM64 — отдельной сборки нет; на ARM64-устройствах запускайте x64-версию через штатную эмуляцию Windows.

Установка и запуск

Установщика нет — программа поставляется одним файлом ErrantLauncher-x64.exe.

  1. Скопируйте файл в любую папку: Документы, отдельный каталог на диске или USB-накопитель.
  2. Запустите его двойным щелчком.
  3. При первом запуске рядом с файлом программы создаётся папка ErrantLauncher — в ней хранятся все карточки, настройки и служебные данные.
Внимание

Предупреждение SmartScreen. Исполняемый файл не подписан цифровой подписью, поэтому Windows может показать предупреждение — это ожидаемо для бета-версии. Как проверить подлинность файла: FAQ.

Требования к экрану

Окна программы имеют фиксированный размер — изменить его нельзя:

  • содержимое окна: 1000 × 620 DIP;
  • внешний габарит окна с учётом декоративной тени: 1028 × 648 DIP.

DIP — это логические единицы размера интерфейса, а не физические пиксели экрана. Фактический размер окна в пикселях зависит от масштаба Windows (например, при масштабе 150 % окно займёт примерно 1540 × 970 физических пикселей).

Для полного отображения интерфейса рабочая область экрана (экран без панели задач) должна вмещать окно целиком. Высокие значения масштаба уменьшают рабочую область в логических единицах и могут потребовать более высокого разрешения экрана.

Если рабочая область меньше габарита окна, часть окна при центрировании может оказаться за краями экрана, включая верхнюю панель с кнопками сворачивания и закрытия.

Совет

На практике: на типичных десктопах (1920 × 1080 и выше) при масштабе 100–150 % окно помещается полностью. На экранах с низким разрешением и высоким масштабом (например, 1366 × 768 при 125–150 %) рабочей области может не хватить — проверьте отображение на своём экране при первом запуске.

Диск и права доступа

  • Расположение. Программа должна лежать в папке, из которой разрешено чтение; для сохранения данных нужна и возможность записи.
  • Запись. Если папка ErrantLauncher доступна только для чтения, программа откроется в режиме только чтения: карточки можно просматривать и запускать, но изменения не сохраняются — об этом выводится понятное уведомление.
  • Реестр и профиль. Программа ничего не пишет в реестр Windows и в папки профиля пользователя — все данные живут только в ErrantLauncher\ рядом с exe-файлом.
  • Временная папка. При каждом запуске однофайловое приложение распаковывает свои библиотеки в %TEMP%\.net\ErrantLauncher. Эти каталоги накапливаются и не очищаются автоматически; их можно безопасно удалить вручную, пока программа закрыта.

Запуск с USB-накопителя

Программа рассчитана на запуск со сменных носителей:

  • весь комплект — exe-файл и папка ErrantLauncher — переносится как есть;
  • буква диска может меняться между компьютерами: данные ищутся рядом с исполняемым файлом, а не по абсолютному пути.

Ограничения:

  • извлечение USB-носителя во время работы может завершить процесс — закрывайте программу перед извлечением;
  • если накопитель временно недоступен, программа сообщает «Нет носителя» и хранит изменения в памяти до его повторного подключения;
  • карточки, ссылающиеся на файлы с буквой диска (например, D:\Tools\app.exe), могут не открыться на компьютере, где этой буквы нет.

Известные ограничения совместимости

  • Только Windows; версий для macOS и Linux нет.
  • Только x64; сборок x86 и ARM64 нет.
  • Исполняемый файл не подписан — ожидайте предупреждение SmartScreen.
