Системные требования и совместимость

Errant Launcher — переносная программа для Windows. Установка не требуется: скачайте ZIP-архив, распакуйте его и запустите приложение.

Минимальные требования

ПараметрТребование
Операционная системаWindows 10 версии 1607 или новее
Архитектура64-разрядная (x64)
.NETОтдельная установка не требуется — среда выполнения встроена в приложение (Native AOT)
УстановкаНе требуется — программа запускается из распакованной папки
Свободное местоДостаточно места для приложения, необходимых библиотек и пользовательских данных

Не поддерживаются:

  • Windows 7, Windows 8 и Windows 8.1;
  • 32-разрядные версии Windows;
  • отдельная сборка для ARM64 отсутствует.

На ARM64-устройствах под управлением Windows, поддерживающей эмуляцию x64-приложений, можно запускать версию Errant Launcher для x64.

Требования к экрану

Окно программы имеет фиксированный размер — изменить его нельзя.

Размер окна в физических пикселях зависит от разрешения экрана и масштаба Windows. При увеличенном масштабе окно занимает больше физических пикселей, поэтому на экранах с небольшим разрешением ему может не хватить места для полного отображения.

На типичных настольных компьютерах с разрешением 1920 × 1080 при масштабе 100–150 % окно обычно помещается полностью. При низком разрешении и высоком масштабе, например 1366 × 768 при 150 %, часть окна может оказаться за пределами рабочей области экрана.

Проверьте отображение окна при первом запуске, особенно если используете небольшое разрешение или увеличенный масштаб.
