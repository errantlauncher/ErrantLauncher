Документация/Гайд

Errant Launcher — Руководство пользователя

1. Знакомство с Errant Launcher

Errant Launcher — переносимая (portable) программа для Windows. Она собирает в одном окне карточки для запуска всего, чем вы часто пользуетесь: программ, скриптов, папок, файлов, команд, ссылок, ярлыков и установщиков MSI.

Устанавливать программу не нужно: достаточно распаковать ZIP-архив и запустить EXE-файл. Папку с программой можно переносить — например, держать на флешке и запускать на компьютере с подходящей системой (см. «Системные требования»: Windows 10 версии 1607+, 64-разрядная).

Карточки можно разложить по разделам и категориям, отмечать избранным, искать, запускать по одной или целыми группами.

Как читать это руководство. Можно идти по порядку — от первого запуска до продвинутых возможностей. Можно открывать только нужную главу: каждая самостоятельна, а связанные места связаны ссылками.

Обозначения: названия кнопок и пунктов меню даны в кавычках («Редактор», «Сохранить»). Блок «Важно» — предупреждение о действии, которое нельзя отменить. Блок «Совет» — подсказка для удобства.

2. Первый запуск

  1. Скачайте ZIP-архив на странице загрузки и распакуйте его в любую папку, куда разрешена запись — подойдёт даже флешка.
  2. Убедитесь, что ErrantLauncher-x64.exe, libSkiaSharp.dll и av_libglesv2.dll лежат вместе — без DLL программа не запустится.
  3. Запустите ErrantLauncher-x64.exe. Рядом появится папка данных ErrantLauncher — в ней будут лежать ваши карточки и настройки (подробнее — глава 10).

При первом запуске Windows SmartScreen может предупредить о неизвестном издателе — файл не подписан сертификатом. Выберите «Подробнее» → «Выполнить в любом случае».

Если программа уже работает, второй экземпляр не создаётся — откроется существующее окно (или оно восстановится из трея).

3. Главное окно

После запуска вы видите:

  • строка заголовка сверху — окно можно перетаскивать за её свободную область; справа кнопки «свернуть», «развернуть», «закрыть»;
  • боковая панель слева — пункт «Избранное» и список разделов;
  • «пилюли» категорий под заголовком — категории выбранного раздела;
  • панель инструментов справа вверху — поле «Поиск…», кнопки «Редактор», сортировки и настроек;
  • сетка карточек в центре;
  • кнопка состояния слева внизу — открывает информационную панель со счётчиками и индикаторами.

В правом нижнем углу могут стоять метки: «Режим администратора» (программа запущена от имени администратора), «Только чтение» и «Нет носителя» (проблемы с папкой данных — глава 10).

Щелчок по пустому месту панели сворачивает/разворачивает её. Правый щелчок по разделу открывает меню «Переименовать», «Скрыть раздел», «Удалить раздел»; по пилюле категории — «Переименовать», «Скрыть».

Поиск. Введите текст в «Поиск…» — сетка отфильтруется. Ищется по названию карточки, имени целевого файла и описанию; все слова запроса должны совпасть. Esc в поле очищает поиск. Пока идёт поиск, «Редактор» недоступен — сначала очистите поле.

Сортировка. Кнопка сортировки открывает варианты: «Свой порядок», «По имени», «По типу», «По частоте запуска». Последний поднимает вверх то, что вы открываете чаще.

Системный трей. Если в настройках включено «Сворачивание в трей», кнопка «закрыть» прячет окно в область уведомлений вместо выхода. Щелчок по значку возвращает окно; меню значка: «Открыть» и «Выход». Если выключить настройку, пока окно спрятано, оно вернётся на экран.

4. Первые карточки

Четыре термина, которые понадобятся дальше:

  • Карточка — кнопка в сетке, запускающая один объект.
  • Категория — подгруппа внутри раздела (пилюли над сеткой).
  • Раздел — верхний уровень группировки (список слева).
  • Избранное — отдельный вид с отмеченными карточками всех разделов.

Три способа добавить карточку:

  1. Перетаскивание. Перетащите файл или папку прямо на окно — тип определится автоматически (.exe → программа, .lnk → ярлык, .msi → MSI, скрипт → скрипт, папка → папка, остальное → файл). Можно перетащить и текст ссылки http(s):// — создастся URL-карточка.
  2. Редактор. «Редактор» → «Добавить карточку» → выберите тип → заполните поля → «Сохранить».
  3. Массовый импорт. Для добавления целой папки объектов сразу — см. главу 8.

Карточка появится в текущих разделе и категории. Если разделов ещё нет, при перетаскивании создастся служебный раздел для входящих.

Начните так: «Редактор» → вкладка «Структура» → «Добавить раздел» и «Добавить категорию» → вернитесь в главное окно, выберите их → добавьте первую карточку.

5. Карточки подробно

Общие поля

  • Название — обязательно; видно на карточке и ищется.
  • Описание — необязательно; тоже участвует в поиске.
  • Раздел и категория — куда положить карточку.
  • Значок — выбор через окно значков (глава 9).
  • «Запуск от имени администратора» — у типов, где имеет смысл (программа, скрипт, команда, ярлык, MSI).

Одинаковые названия допустимы — программа покажет подсказку о совпадении, но не блокирует сохранение.

Пути. Можно указывать относительные пути (от папки программы — лучше для переноса) и абсолютные (C:\…). Абсолютные могут перестать работать на другом компьютере — глава 10.

Кнопка «Сохранить» активна только после заполнения обязательных полей. Закрытие редактора с несохранёнными правками спросит «Отменить несохранённые изменения?».

5.1. Программа

Запускает .exe. Поля: название, варианты запуска, аргументы, рабочая папка, значок, «от имени администратора».

Варианты запуска — можно хранить несколько .exe под разные архитектуры Windows (x86, x64, ARM64). «Обзор…» добавляет файл, программа сама определит архитектуру и пометит строку. Повторный выбор той же архитектуры заменяет путь. При запуске выбирается вариант под вашу систему; в меню карточки можно запустить конкретный («Запустить x64» и т.п.).

Проверки: хотя бы один вариант обязателен, файл .exe должен существовать, рабочая папка — существующий каталог.

5.2. Скрипт

Запускает файлы-сценарии (bat, ps1, reg, vbs и др. — тип определяется по расширению). Поля: название, файл, рабочая папка, значок, «от имени администратора».

При запуске всегда спрашивается подтверждение — показывается имя и описание. Для .reg — отдельное предупреждение об изменении реестра.

5.3. Папка

Открывает каталог в Проводнике. Поля: название, путь к папке, значок. Путь обязан существовать и указывать именно на папку.

5.4. Файл

Открывает документ/медиа ассоциированным приложением. Поля: название, путь, значок. Файл должен существовать; расширения с собственными типами (.exe, .lnk, .msi, скрипты) зарезервированы.

5.5. Ярлык Windows

Запускает существующий .lnk. Поля: название, путь к .lnk, значок, «от имени администратора». Файл должен оканчиваться на .lnk и существовать.

5.6. Команда

Выполняет текстовую команду (как в командной строке). Поля: название, текст команды, «от имени администратора».

При запуске — диалог подтверждения; после выполнения окно консоли остаётся открытым, чтобы вы могли прочитать вывод — закройте его вручную. Пункт меню «Копировать команду» кладёт текст в буфер без запуска.

5.7. URL / URI

Открывает ссылку в браузере или приложении-обработчике. Поля: название, адрес, значок. Принимаются только безопасные схемы — опасные будут отклонены. Пункт «Копировать ссылку» — адрес в буфер.

5.8. MSI-пакет

Запускает установщика .msi. Поля: название, путь (обзор с фильтром «MSI-пакет»), аргументы установщика, значок, «от имени администратора». Битая строка аргументов (незакрытая кавычка, ключ без значения, аргумент-указатель на другой пакет) вызовет ошибку — проверьте поле «Аргументы».

5.9. Группа карточек

Запускает несколько карточек подряд. Создание и запуск — в главе 6.

6. Запуск и действия с карточками

Основной запуск — щелчок левой кнопкой. Меню карточки — правой; состав зависит от типа: «Запустить», запуск конкретной архитектуры, запуск с правами или без, «Открыть расположение» (Проводник с выделенным файлом), «Копировать путь/команду/ссылку», «Изменить», «Добавить в избранное», «Удалить».

Подтверждения — перед скриптами, командами и группами с такими участниками программа спрашивает подтверждение: защита от случайного запуска.

Запуск от имени администратора. У карточки можно включить «Запуск от имени администратора» — тогда при запуске Windows покажет запрос UAC; отказ просто отменит запуск. Если сам Errant Launcher запущен от имени администратора (метка «Режим администратора»), все применимые карточки получат повышение автоматически — независимо от их галки, и бейдж «Админ» появится на всех таких карточках. На папки и ссылки это не действует — они открываются обычным образом. Рекомендация: запускайте лаунчер с обычными правами и повышайте только нужные карточки.

Группы карточек. Создаётся в Редакторе → «Группа» → выбор участников из списка (есть поиск и фильтры). Группа обязана содержать хотя бы одного участника; вложенные группы недопустимы. У участников можно задать задержку перед запуском следующего. При запуске открывается диалог «Запуск группы»: счётчик «N из M», обратный отсчёт «Следующая: … — через X с», строки «запущена / отменена / не запущена». «Отменить оставшиеся» или Esc останавливают очередь — уже запущенное не откатывается. Итог: «Запущено: X · Ошибок: Y · Пропущено: Z».

Аргументы и рабочая папка (программа, скрипт, MSI) задаются в форме карточки; пустая рабочая папка = папка цели.

7. Организация коллекции

Разделы и категории управляются в Редакторе → «Структура»: «Добавить раздел» / «Добавить категорию», переименование, порядок («вверх»/«вниз»), скрытие (тумблер видимости), смена значка раздела, удаление.

Правила: имена не пустые и уникальные в пределах уровня — при совпадении программа сообщит «уже существует». Скрытый раздел пропадает из боковой панели, скрытая категория — из пилюль; данные не удаляются и возвращаются обратно.

Важно — удаление: удаление раздела безвозвратно удаляет все его категории и карточки; удаление категории — все её карточки. Программа предупредит в диалоге.

Избранное. Правый щелчок по карточке → «Добавить в избранное» / «Убрать из избранного». Пункт «Избранное» в боковой панели открывает вид с вкладками типов («Все», «Программы», «Скрипты»…). Поиск работает и здесь. При экспорте/импорте отметки путешествуют вместе с карточками.

Работа с карточками. «Изменить» в меню карточки открывает её форму. «Редактор» → «Редактировать карточки» — таблица со всеми карточками: поиск, фильтры по типу и разделу, сортировка колонок, мультивыбор, «Переместить» (в другую категорию), «Дублировать», «Удалить». Удаление необратимо — карточка пропадёт из раздела, избранного и всех групп.

8. Массовый импорт

Для добавления целой папки объектов сразу. «Редактор» → вкладка «Массовый импорт». Мастер: «Выбор папки» → «Сканирование» → «Результаты» → «Куда добавить» → итог.

Фильтры: глубина обхода (без ограничений или 1–3 уровня), рекурсия, лимит «Максимум кандидатов», пилюли типов (программы — с выбором архитектур, скрипты — с выбором типов, файлы — со списком расширений include/exclude, MSI и ярлыки — без доп. фильтров), пропуск скрытых/системных/junction-точек, «Сканировать сетевые пути (UNC)», исключаемые имена папок.

Сканирование показывает счётчики «Просмотрено объектов», «Кандидатов», «Предупреждений». «Остановить» прерывает — найденное сохраняется.

Результаты — таблица со статусами («готово», «проверить», «пропал», «ошибка») и метками («уже существует», «нельзя добавить») с причинами. Возможности: поиск, фильтры, «Повторная проверка» выбранных файлов без нового скана, разворачивание строки для правки полей, «Снять выбор»/«Исключить выбранные». Кандидаты с ошибками и дубликаты исключаются автоматически — но их можно включить вручную.

«Куда добавить»: раздел — существующий или «Новый раздел…»; категория — существующая, «Новая категория…», «Без категории» или «По имени родительской папки». Кнопка «Проверить» показывает анализ: «Будет добавлено / Пропустим / Требуют внимания», конфликты имён и предупреждение о путях с буквой диска.

«Импортировать N карточек» — запись в фоне; перед ней автоматически создаётся проверенная резервная копия. Итог: «Добавлено», «Пропущено при импорте», «Не выбрано». При частичной записи или сбое программа укажет путь к резервной копии для ручного отката.

9. Внешний вид и настройки

Настройки открываются кнопкой в правом верхнем углу — панель поверх окна; Esc закрывает.

Оформление

  • Тема — цветовая тема окна.
  • Акцентный цвет — акцент интерфейса и значка в трее.
  • Стиль значков карточек — «Цвета темы» / «Акцентный цвет» / «Разноцветные».
  • Стиль бейджиков — оформление индикаторов на карточках.

Поведение

  • Начальный раздел — какой раздел открыт при запуске.
  • Сворачивание в трей — закрытие прячет окно в трей вместо выхода (глава 3).

Язык

  • Язык — язык интерфейса, 6 вариантов.

Все изменения применяются сразу и сохраняются автоматически. В режиме «Только чтение» настройки действуют до закрытия, но не сохраняются.

Значки карточек и разделов — кнопка выбора значка в форме карточки и в «Структуре»: встроенный значок типа, коллекция встроенных значков, собственный PNG, «Извлечь» из .exe/.lnk, «Сброс». Если извлечь не удалось или файл не PNG — ошибка, значок не пострадает.

В этой же панели — кнопки «Импорт», «Экспорт», «Сбросить все данные» и «О программе» (версия, статистика карточек, лицензии, ссылки на сайт и GitHub).

10. Данные: хранение, перенос и резервные копии

Где лежат данные. Папка ErrantLauncher рядом с exe-файлом: в ней файлы разделов с карточками (sections\), настройки (settings.json), состояние (state.json), ваши значки (custom-icons\), журналы (logs\) и служебные резервные копии. Всё в одном месте — именно это делает программу переносимой.

Пути в карточках. Относительные пути переживают перенос вместе с программой; абсолютные (D:\Tools\app.exe) работают только там, где такой путь существует — на другом компьютере с другой буквой диска такая карточка покажет «Ошибка». Папка данных сама букве диска не привязана.

Перенос на другой компьютер — скопируйте целиком всё: ErrantLauncher-x64.exe + обе DLL + папку ErrantLauncher. Запустите — коллекция и настройки на месте. Перед переносом сделайте полную резервную копию.

Два вида экспорта (настройки → «Экспорт»):

  • Полная резервная копия — всё: разделы, иконки, настройки, состояние. ErrantLauncher-Backup.zip.
  • Поделиться коллекцией — выбранные разделы, иконки и избранное, без настроек. ErrantLauncher-Collection.zip.

Импорт (настройки → «Импорт»): выберите .zip → подтвердите → отметьте нужные данные → при совпадении имён разделов выберите «Заменить / Переименовать / Пропустить». Перед записью создаётся резервный снимок — при ошибке данные откатываются.

USB-накопитель. Поддерживается. Извлечённая на ходу флешка переводит программу в режим «Нет носителя»: данные остаются на экране, изменения — в памяти и сохранятся, если вернуть носитель до закрытия программы. Режим «Только чтение» — когда записать нельзя: карточки видны и запускаются, изменения действуют только до закрытия.

Подробное описание состава папки и механизмов копий — на странице «Данные и переносимость».

11. Сброс и восстановление

Восстановление из резервной копии

Из экспортированного файла: настройки → «Импорт» → выберите ErrantLauncher-Backup.zip → отметьте «Настройки» и нужные данные → решите конфликты → проверьте результат.

Из копии папки: закройте программу, сохраните текущую папку ErrantLauncher отдельно на всякий случай, верните содержимое резервной копии на место, запустите программу.

Возврат папки данных

Папку ErrantLauncher можно переносить и возвращать как единое целое — все карточки, настройки и значки вернутся вместе с ней. Замену всегда делайте при закрытой программе и храните копию заменяемой папки до проверки результата.

Удаление всех данных

Важно — действие необратимо. «Сбросить все данные» удаляет все разделы, категории, карточки, избранное, настройки и состояние — программа перезапустится чистой.

Настройки → «Сбросить все данные» → два последовательных диалога подтверждения. Перед сбросом сохраните данные: полная резервная копия через экспорт или копия папки ErrantLauncher — обе позволяют вернуть коллекцию позже.
