Документация/FAQ

Часто задаваемые вопросы

Ответы на типичные вопросы и решения распространённых проблем Errant Launcher. Подробные инструкции — в разделах «Данные и переносимость», «Системные требования» и «Поддержка».

Приложение не запускается

  • Убедитесь, что система подходит: Windows 10 (1607) или новее, 64-разрядная. См. системные требования.
  • Проверьте, что рядом с ErrantLauncher-x64.exe лежат обе DLL: libSkiaSharp.dll и av_libglesv2.dll. Без них программа не стартует.
  • Убедитесь, что у программы есть права на запись в её папку — без них она не сможет создать папку данных.
  • Если программа не реагирует — проверьте ErrantLauncher\logs\bootstrap.log и app.log: первые строки ошибки обычно там.

Windows SmartScreen предупреждает о неизвестном издателе

Это ожидаемо: исполняемый файл не подписан сертификатом кода. Выберите «Подробнее» → «Выполнить в любом случае». Перед запуском можно сверить контрольную сумму файла с опубликованной на странице загрузки или в SHA256SUMS.txt из архива.

Нужен ли установленный .NET?

Нет. Программа собрана с Native AOT — среда выполнения встроена в EXE-файл. Отдельная установка .NET не требуется.

«Errant Launcher уже запущен»

Работает одновременно только один экземпляр программы. Если окна не видно, проверьте область уведомлений (трей) — программа могла быть свёрнута туда. Если процесс «завис» в памяти, завершите его через Диспетчер задач и запустите заново.

Как добавить карточки?

Три способа:

  • Перетащите файл, папку или ярлык прямо на окно лаунчера.
  • Редактор — добавьте разделы, категории и карточки вручную.
  • Массовый импорт — сканирует папки: найденные программы, файлы, скрипты и ярлыки станут карточками.

Режимы «Только чтение» и «Нет носителя»

«Только чтение» — папка данных недоступна для записи. Карточки видны и запускаются, но изменения не сохраняются на диск и действуют только до закрытия программы. Поэтому в этом режиме не сохраняются настройки и правки в Редакторе.

«Нет носителя» — диск с папкой данных отключён (например, извлечённый USB). Изменения остаются в памяти и могут записаться, если носитель вернуть до закрытия программы. Если закрыть приложение раньше — они будут потеряны.

Диалог «Файл повреждён»

Программа не смогла прочитать один из файлов данных. Файл не изменяется автоматически — вы решаете: удалить его или оставить как есть. Перед удалением файлов раздела программа автоматически делает копию в .backup\. Если проблема системная, сначала сохраните копию папки ErrantLauncher.

Запуск с USB-накопителя

Поддерживается — данные живут рядом с exe-файлом. Учтите:

  • карточки с абсолютными путями (D:\Tools\app.exe) не откроются на компьютере без этой буквы диска;
  • при извлечении накопителя появится статус «Нет носителя» — см. раздел выше.

Подробности — в «Данные и переносимость».

Карточка не запускается

Проверьте по порядку:

  • «Файл отсутствует» — целевого файла нет по сохранённому пути. Проверьте, существует ли файл; при смене буквы диска исправьте путь в карточке.
  • «Носитель отсутствует» — диск с целевым файлом не подключён. Подключите его и попробуйте снова.
  • Метка «Ошибка» — запуск не удался. Причины: файл удалён, нет прав, блокировка антивируса, неверная команда. Текст ошибки — в журнале.
  • Ошибка при запросе прав — запуск от администратора требует подтверждения UAC. Отказ просто отменяет запуск — это не ошибка;
  • Команда или ссылка не открывается — проверьте текст команды/URL; Windows запускает браузер или приложение по типу адреса.

Карточка-команда оставляет окно консоли

Командные карточки выполняются через командный процессор, а окно консоли остаётся открытым намеренно — чтобы вы могли просмотреть вывод команды. Закройте его вручную, когда результат больше не нужен.

Массовый импорт завершился частично или с ошибками

Перед импортом программа создаёт резервную копию в .mass-import-backups\ и проверяет её по SHA-256. Хранится одна последняя проверенная копия — её можно восстановить вручную при закрытой программе. Частичный результат — нормальное поведение: отфильтрованные по типу, расширению или архитектуре файлы в коллекцию не попадают. Подробности — в документации о данных.

Чем полная копия отличается от «Поделиться коллекцией»?

  • Полная резервная копия — всё: разделы, иконки, настройки, состояние. Имя ErrantLauncher-Backup.zip.
  • Поделиться коллекцией — разделы, иконки и избранное, без настроек. Имя ErrantLauncher-Collection.zip.

Пропали карточки или настройки — куда они записываются?

Все данные — в папке ErrantLauncher рядом с exe-файлом: sections\*.json (карточки), settings.json, custom-icons\. Если программа открылась «пустой» — проверьте, не запущен ли другой exe (или exe из другой папки), и не сработал ли режим «Только чтение».

Окно не помещается на экране

Окно имеет фиксированный размер — изменить нельзя. При высоком масштабе Windows на экранах с низким разрешением (например, 1366×768 при 150%) окно может не поместиться. Уменьшите масштаб в настройках дисплея или используйте экран с большим разрешением.

«Данные созданы более новой версией»

Папку данных заполнила более новая версия программы. Файлы читаются, но не перезаписываются — чтобы не повредить формат. Обновите программу до актуальной версии.

Обновление без потери данных

Автообновления нет. Закройте программу, распакуйте новый ZIP и замените все файлы приложения — EXE и обе DLL вместе, не только EXE. Папку ErrantLauncher не трогайте — коллекция и настройки сохранятся. Детали — в разделе об обновлении.

Где журналы и как сообщить об ошибке

Журналы: ErrantLauncher\logs\app.log и bootstrap.log. Перед отправкой откройте их в Блокноте и удалите сведения, которые не хотите раскрывать — в путях могут быть имена ваших папок. Создайте issue на GitHub: версия программы («О программе»), версия Windows (winver), шаги воспроизведения, текст ошибки. Подробно — на странице «Поддержка».
