Внимание

Бета-версия. Это предварительная версия программы. Возможны ошибки и изменения. Об ошибках сообщайте здесь — это помогает быстрее выпустить стабильную версию.

[!NOTE] Скачивается один exe — установщика и архива нет. Один файл: Windows x64 (64-разрядная).

Требования

  • Windows 10 или 11, 64-разрядная (x64).
  • Папка с правом записи — приложение хранит данные рядом с exe. Избегайте Program Files и других защищённых мест, если не запускаете от имени администратора.
  • Около 50 МБ на exe и немного места под данные.
  • При первом запуске Windows SmartScreen может предупредить о неизвестном издателе — выберите «Подробнее» → «Выполнить в любом случае». Для уверенности сверьте хэш SHA-256 выше (проверка: Частые вопросы).

Первый запуск

  1. Положите exe в папку с правом записи — подойдёт и флешка.
  2. Запустите. Рядом появится папка данных ErrantLauncher\.
  3. Добавьте карточки — перетащите файлы на окно или используйте Редактор. Готово.
