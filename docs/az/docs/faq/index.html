Tətbiq başlanmır

Mümkün səbəblər: köhnə Windows versiyası; dəstəklənməyən arxitektura; artıq işləyən nüsxə; əlçatmaz məlumat qovluğu.

Nəyi yoxlamalı:

  1. Windows 64-bit olmalı, Windows 10 (1607) və ya daha yeni versiya. Windows 7/8 və 32-bit sistemlər dəstəklənmir.
  2. Bildiriş sahəsinə (trey) baxın — proqram artıq işləyib bükülmüş ola bilər.
  3. ErrantLauncher qovluğunun exe-nin yanında mövcud olduğunu və oxuna bilməsini yoxlayın.

Nəyi sınamalı: exe faylını lokal diskdə adi qovluğa köçürün (məsələn, C:\Tools\) və yenidən işə salın; ErrantLauncher\logs\bootstrap.log jurnalını yoxlayın — o, başlanğıc qəzalarında yaradılır.

Dəstəyə bildirmək: Windows versiyasını, exe faylının yerini və bootstrap.log məzmununu (varsa).

SmartScreen xəbərdarlığı

Səbəb: icra faylı rəqəmsal imza ilə imzalanmayıb — beta versiyası üçün bu gözləniləndir, problemin əlaməti deyil.

Nəyi yoxlamalı (tövsiyə olunur): faylın orijinallığını nəzarət cəmi ilə. Proqram qovluğunda PowerShell-də:

Get-FileHash .\ErrantLauncher-x64.exe -Algorithm SHA256

Nəticəni reliz dəstindəki SHA256SUMS.txt faylındakı sətirlə müqayisə edin.

Nə etməli: SmartScreen pəncərəsində «Ətraflı» → «Bərabər işə sal» vurun. SmartScreen-i və ya Windows-un digər müdafiəsini söndürmək tələb olunmur və tövsiyə edilmir.

Quraşdırılmış .NET lazımdırmı

Yox. .NET iş mühiti icra faylına daxildir — proqram quraşdırılmış .NET olmadan təmiz Windows-da işləyir.

Tək-fayl təqdimatının əks tərəfini nəzərə alın: hər başlanğıcda proqram kitabxanaları %TEMP%\.net\ErrantLauncher-ə açır. Kataloqlar yığılır — tətbiq bağlı ikən onları əllə silmək olar.

«Errant Launcher artıq işləyir»

Səbəb: proqramın yalnız bir nüsxəsi işləyir; ikinci başlanğıc bu bildirişi göstərir.

Nəyi yoxlamalı: bildiriş sahəsi (trey) — proqram ora bükülmüş ola bilər; işləyən nüsxə ilə əlaqə qurmaq alınmazsa, proqram bunu ayrıca bildirəcək.

Nəyi sınamalı: prosesi trey menyusundan «Çıxış» və ya Task Manager ilə bağlayın və yenidən işə salın.

«Yalnız oxu» rejimi və «Daşıyıcı yoxdur»

Səbəblər:

  • Yalnız oxu — proqramın məlumat qovluğuna yazma icazəsi yoxdur (qorunan daşıyıcı, giriş icazələri, karantin).
  • Daşıyıcı yoxdur — məlumat qovluğu müvəqqəti əlçatan deyil (USB-yaddaş ayrılıb).

Nə baş verir: yalnız oxu rejimində kartlara baxmaq və onları işə salmaq olar, lakin dəyişikliklər aydın mesajla rədd edilir. «Daşıyıcı yoxdur» halında dəyişikliklər yaddaşda qalır və daşıyıcı yenidən qoşulduqdan sonra saxlanılacaq — proqram «Daşıyıcı yenidən qoşulub» deyə bildirəcək.

Nəyi yoxlamalı: ErrantLauncher qovluğunun exe-nin yanında olub-olmadığını; onda «yalnız oxu» atributu olub-olmadığını; eyni məzmunlu daşıyıcının qoşulub-qoşulmadığını.

«Fayl zədəlidir»

Nə baş verdi: məlumat fayllarından biri (məsələn, bölmə və ya parametr faylı) oxunmur. Proqram belə faylı nəzərə almır və dəyişmir — qalan məlumatlarınız təhlükəsizdir.

Nə təklif olunur: dialoqda — zədələnmiş faylı «Sil» və ya onu «Saxla» (məsələn, əllə bərpa etməyə cəhd üçün).

Nəyi sınamalı: faylı ehtiyat nüsxədən bərpa edin — ixrac edilmiş arxivdən «Konfiqurasiya idxalı» ilə və ya əllə məlumat qovluğundakı .backup\/.mass-import-backups\-dən.

USB-yaddaşdan icra

Normal: bu standart ssenaridir — exe və ErrantLauncher qovluğunu birlikdə daşıyın.

Tipik problemlər:

  • Proqram çıxarılma zamanı bağlandı — daşıyıcını çıxarmazdan əvvəl onu bağlayın.
  • Kartlar başqa kompüterdə işə salınmır — onlar fayllara lokal yollarla istinad edir; kart statuslarını və yolları yoxlayın.
  • Dəyişikliklər saxlanılmır — «Yalnız oxu» rejimi bölməsinə baxın.

Əmr-kartı konsol pəncərəsi qoyur

Bu xüsusiyyətdir, xəta deyil. Əmrlər cmd /k və ya powershell -NoExit ilə icra olunur ki, nəticə ekranda qalsın. Nəticə artıq lazım olmadıqda konsol pəncərəsini əllə bağlayın.

Həmçinin nəzərə alın: əmrlər həmişə proqramın məlumat qovluğundan icra olunur — əmr-kartlarının ayrıca işçi qovluğu yoxdur. Əmrə başqa qovluq lazımdırsa, onu cd /d "yol" ilə başladın (və ya yolu əmrin içində göstərin).

Kart «Fayl yoxdur» və ya «Daşıyıcı yoxdur» göstərir

Səbəb: proqram kart hədəflərinin əlçatanlığını yoxlayır. Statuslar:

Status Mənası
Əlçatandır Hədəf tapıldı
Fayl yoxdur Göstərilən yolda fayl yoxdur
Mənbə əlçatan deyil Qovluq/mənbə oxunmur
Daşıyıcı yoxdur Disk/yaddaş qoşulmayıb
Yoxlanılır… Yoxlama gedir

Nəyi yoxlamalı: faylın göstərilən yolda mövcud olub-olmadığını; lazımi diskin qoşulub-qoşulmadığını (xüsusən launcher-in başqa kompüterə köçürülməsindən sonra). Yolu «Kartları redaktə et»-də düzəltmək olar.

Toplu idxal qismən və ya səhvlərlə başa çatdı

Mümkün səbəblər: yol və ad dublikatları, əlçatmaz fayllar, filtrlərlə söndürülmüş tiplər, namizəd limitinə çatma, yazma səhvləri.

Nəyi yoxlamalı: idxalın yekun hesabatı səbəbləri sadalayır («dublikat: artıq kart var», «ad artıq istifadə olunur», «itdi — fayl tapılmadı»). Nəticələr ekranındakı qeydlər filtrlərin nəyi kəsdiyini göstərir: tiplər, arxitekturalar, genişlənmələr, istisna edilmiş qovluqlar.

Nəyi sınamalı: filtrləri və seçimi düzəldin; yeni skan əvəzinə «Təkrar yoxlama»dan istifadə edin.

Yazı kəsilibsə: idxaldan əvvəl avtomatik ehtiyat nüsxə yaradılır (.mass-import-backups\-də). Xəta mesajı onun yolunu və tədbiri göstərir: məzmununu məlumat qovluğunun üstünə köçürün və ya idxalı təkrarlayın. Məlumat qovluğunu əllə silməyin — bu, ehtiyat nüsxələri də məhv edər.

Pəncərə ekrana sığmır

Səbəb: proqram pəncərələri sabit ölçüdədir (məzmun 1000 × 620 DIP, xarici ölçü 1028 × 648 DIP). Ekranın iş sahəsi daha kiçikdirsə — məsələn, aşağı imkan yüksək Windows miqyası ilə birlikdə — pəncərənin bir hissəsi ekran kənarlarından, o cümlədən pəncərə düyməli yuxarı paneldən kənara çıxa bilər.

Nəyi yoxlamalı: Windows miqyası (Parametrlər → Sistem → Ekran → Miqyas) və ekran imkanı.

Nəyi sınamalı: Windows miqyasını azaltmaq və ya daha yüksək imkan seçmək; pəncərənin bir hissəsi ekrandan kənardadırsa — miqyası dəyişin və proqramı yenidən başladın ki, pəncərə yenidən mərkəzləşsin.

Ətraflı: Sistem tələbləri.

Yeniləmə və məlumatların saxlanması

Yeniləmə: avtomatik yeniləmə yoxdur — proqram bağlı ikən exe faylını əvəz edin; ErrantLauncher qovluğuna toxunmayın.

Yeniləmədən sonra məlumatlar: saxlanılır. Məlumat faylları proqramın daha yeni versiyası ilə yaradılıbsa, köhnə versiya onları oxuyacaq, lakin dəyişməyəcək — proqramı yeniləyin.

Kartların sıralanması: seçilmiş sıralama qaydası yalnız sessiya üçün saxlanılır — yenidən başladıqdan sonra standart qayda tətbiq olunur. Bu, betanın məlum məhdudiyyətidir, məlumat itkisi deyil.

Jurnalları harada axtarmaq və xəta barədə necə məlumat vermək

Jurnallar: exe-nin yanında ErrantLauncher\logs\ — app.log (iş mesajları və səhvlər) və bootstrap.log (başlanğıc qəzaları). Jurnallar heç yerə avtomatik göndərilmir.

Xəta barədə necə məlumat vermək: addım-addım təlimat, nə əlavə etməli və hara yazmalı — sənəddə Dəstək və xəta məlumatları.
