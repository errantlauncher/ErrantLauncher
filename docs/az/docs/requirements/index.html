Sistem tələbləri və uyğunluq

Errant Launcher portativ proqramdır: ona yalnız uyğun Windows nəşri və bir az boş yer lazımdır. Aşağıda təsdiqlənmiş tələblər, tövsiyələr və cari beta versiyasının məlum məhdudiyyətləri ayrılıb.

Mündəricat

  • Minimal tələblər
  • Quraşdırma və başlanğıc
  • Ekran tələbləri
  • Disk və giriş icazələri
  • USB-yaddaşdan icra

Minimal tələblər

Parametr Tələb
Əməliyyat sistemi Windows 10 versiya 1607 və ya daha yeni
Arxitektura 64-bit (x64)
.NET Tələb olunmur — iş vaxtı mühiti proqram faylına daxildir
Quraşdırma Tələb olunmur — tək icra faylı
Administrator hüquqları Başlanğıc və iş üçün tələb olunmur

Dəstəklənmir:

  • Windows 7, 8 və 8.1 (istifadə olunan .NET 8 platformasının məhdudiyyəti);
  • Windows-un 32-bit nəşrləri — x86 yığması təqdim olunmur;
  • ARM64 prosessorlar — ayrıca yığma yoxdur; ARM64 cihazlarında x64 versiyasını Windows-un standart emulyasiyası ilə işə salın.

Quraşdırma və başlanğıc

Quraşdırıcı yoxdur — proqram tək fayl ErrantLauncher-x64.exe kimi təqdim olunur.

  1. Faylı istənilən qovluğa köçürün: Sənədlər, diskdə ayrıca kataloq və ya USB-yaddaş.
  2. İkiqat vurunla işə salın.
  3. İlk başlanğıcda proqram faylının yanında ErrantLauncher qovluğu yaradılır — orada bütün kartlar, parametrlər və xidməti məlumatlar saxlanılır.
Diqqət

SmartScreen xəbərdarlığı. İcra faylı rəqəmsal imza ilə imzalanmayıb, ona görə Windows xəbərdarlıq göstərə bilər — bu, beta versiyası üçün gözləniləndir. Faylın orijinallığını necə yoxlamaq: SSS.

Ekran tələbləri

Proqram pəncərələri sabit ölçüyə malikdir — onu dəyişmək olmaz:

  • pəncərənin məzmunu: 1000 × 620 DIP;
  • dekorativ kölgə nəzərə alınmaqla pəncərənin xarici ölçüsü: 1028 × 648 DIP.

DIP — interfeys ölçüsünün məntiqi vahididir, ekranın fiziki pikselləri deyil. Pəncərənin piksellərlə faktiki ölçüsü Windows miqyasından asılıdır (məsələn, 150% miqyasında pəncərə təxminən 1540 × 970 fiziki piksel tutacaq).

İnterfeysin tam göstərilməsi üçün ekranın iş sahəsi (tapşırıq panelsiz ekran) pəncərəni tam sığdırmalıdır. Yüksək miqyas dəyərləri iş sahəsini məntiqi vahidlərdə kiçildir və daha yüksək ekran görüntü imkanı tələb edə bilər.

İş sahəsi pəncərənin ölçüsündən kiçikdirsə, mərkəzləşdiriləndə pəncərənin bir hissəsi ekranın kənarlarından, o cümlədən bükülmə və bağlama düymələri olan yuxarı paneldən kənara çıxa bilər.

Məsləhət

Praktikada: tipik masaüstü kompüterlərdə (1920 × 1080 və yuxarı) 100–150% miqyasında pəncərə tam yerləşir. Aşağı imkanlı ekranlarda yüksək miqyasla (məsələn, 1366 × 768 125–150%-də) iş sahəsi kifayət etməyə bilər — ilk başlanğıcda öz ekranınızda göstərilməni yoxlayın.

Disk və giriş icazələri

  • Yerləşmə. Proqram oxuma icazəsi olan qovluqda olmalıdır; məlumatların saxlanması üçün yazma da lazımdır.
  • Yazma. ErrantLauncher qovluğu yalnız oxunarsa, proqram yalnız oxu rejimində açılır: kartları görmək və işə salmaq olar, lakin dəyişikliklər saxlanılmır — bu barədə aydın bildiriş göstərilir.
  • Reyestr və profil. Proqram Windows reyestrinə və istifadəçi profilinin qovluqlarına heç nə yazmır — bütün məlumatlar yalnız exe faylının yanındakı ErrantLauncher\ qovluğunda yaşayır.
  • Müvəqqəti qovluq. Hər başlanğıcda tək-fayl tətbiq kitabxanalarını %TEMP%\.net\ErrantLauncher-ə açır. Bu kataloqlar yığılır və avtomatik təmizlənmir; proqram bağlı ikən onları əllə silmək təhlükəsizdir.

USB-yaddaşdan icra

Proqram çıxarıla bilən daşıyıcılardan işə salınmaq üçün nəzərdə tutulub:

  • bütün dəst — exe faylı və ErrantLauncher qovluğu — olduğu kimi daşınır;
  • disk hərfi kompüterlər arasında dəyişə bilər: məlumatlar icra faylının yanında axtarılır, mütləq yolla yox.

Məhdudiyyətlər:

  • iş zamanı USB-daşıyıcını çıxarmaq prosesi dayandıra bilər — çıxarmazdan əvvəl proqramı bağlayın;
  • daşıyıcı müvəqqəti əlçatan deyilsə, proqram «Daşıyıcı yoxdur» bildirir və dəyişiklikləri yenidən qoşulana qədər yaddaşda saxlayır;
  • disk hərfi ilə fayllara istinad edən kartlar (məsələn, D:\Tools\app.exe) bu hərfin olmadığı kompüterdə açılmaya bilər.

Məlum uyğunluq məhdudiyyətləri

  • Yalnız Windows; macOS və Linux versiyaları yoxdur.
  • Yalnız x64; x86 və ARM64 yığmaları yoxdur.
  • İcra faylı imzalanmayıb — SmartScreen xəbərdarlığını gözləyin.
