Diqqət

Beta versiyası. Bu, proqramın buraxılışdan əvvəlki yığmasıdır. Səhvlər və dəyişikliklər ola bilər. Problemləri burada bildirin — bu, stabil versiyanı daha tez buraxmağa kömək edir.

Qeyd

Tək exe yüklənir — nə quraşdırıcı, nə arxiv. Bir fayl: Windows x64 (64-bit).

Qeyd

Faylın yoxlanması. İcra faylının rəqəmsal imzası yoxdur — yuxarıdakı SHA-256 heşini yoxlayın və ya VirusTotal hesabatını açın.

Təxminən 70 antivirus mühərrikindən biri (SecureAge) yanlış aşkarlama göstərə bilər. Bu, rəqəmsal imzası olmayan təkfayllı .NET tətbiqi ilə əlaqəli ola bilər. Digər yoxlanmış mühərriklər heç bir təhlükə aşkar etməyib.

Tələblər

  • Windows 10 və ya 11, 64-bit (x64).
  • Yazma icazəsi olan qovluq — proqram məlumatları exe-nin yanında saxlayır. Program Files və digər qorunan yerlərdən qaçının, administrator olaraq işlətmirsinizsə.
  • exe üçün təxminən 50 MB və məlumatlar üçün azca yer.
  • İlk başlanğıcda Windows SmartScreen naməlum yayıncı haqqında xəbərdarlıq göstərə bilər — «Ətraflı» → «Hər halda işə salın» vurun. Əmin olmaq üçün yuxarıdakı SHA-256 heşini yoxlayın (necə yoxlamaq: SSS).

İlk başlanğıc

  1. exe-ni yazma icazəsi olan qovluğa qoyun — fləş-disk uyğundur.
  2. İşə salın. Yanında ErrantLauncher\ məlumat qovluğu yaranır.
  3. Kartlar əlavə edin — faylları pəncərəyə sürüşdürün və ya Redaktordan istifadə edin. Hazırdır.
