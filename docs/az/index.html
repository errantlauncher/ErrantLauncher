Errant Launcher

Lazım olan hər şey. Bir yerdə.

Proqramlar, fayllar, skriptlər və keçidlər — şəxsi məkanınızda kartlar şəklində. Sürətli icra, rahat təşkilatlanma və müxtəlif kompüterlərdə işləmək azadlığı.

Beta yüklə Windows 10/11 · x64

Proqram haqqında

Errant Launcher — Windows üçün portativ icra panelidir; parametrləri və məlumatları icra faylının yanında saxlayır. Proqram quraşdırma tələb etmir: onu USB-yaddaşa və ya başqa qovluğa daşıyıb başqa kompüterdə istifadə etmək olar. Alətlərinizi bölmələr və kateqoriyalar üzrə təşkil edin, tapşırıqları qruplara birləşdirin, axtarışdan istifadə edin və görünüşü özünüzə uyğunlaşdırın. İş məkanınız sizin nəzarətinizdə qalır — proqramı quraşdırmağa ehtiyac yoxdur.

Necə başlamaq

  1. ErrantLauncher-x64.exe faylını istənilən qovluğa köçürün — fləş-disk də olar.
  2. Faylı işə salın. İlk başlanğıcda yanında ErrantLauncher qovluğu yaranır — bütün məlumatlarınız orada olur.
  3. Alətlər panelindən «Redaktor»u açın və ilk kartlarınızı əlavə edin — və ya sadəcə faylları proqram pəncərəsinə sürüşdürün.
