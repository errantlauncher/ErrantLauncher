Proqramlar, fayllar, skriptlər və keçidlər — şəxsi məkanınızda kartlar şəklində. Sürətli icra, rahat təşkilatlanma və müxtəlif kompüterlərdə işləmək azadlığı.

Beta yüklə Windows 10/11 · x64

Proqram haqqında

Errant Launcher — Windows üçün portativ icra panelidir; parametrləri və məlumatları icra faylının yanında saxlayır. Proqram quraşdırma tələb etmir: onu USB-yaddaşa və ya başqa qovluğa daşıyıb başqa kompüterdə istifadə etmək olar. Alətlərinizi bölmələr və kateqoriyalar üzrə təşkil edin, tapşırıqları qruplara birləşdirin, axtarışdan istifadə edin və görünüşü özünüzə uyğunlaşdırın. İş məkanınız sizin nəzarətinizdə qalır — proqramı quraşdırmağa ehtiyac yoxdur.

Hər şey əlinizin altında

Proqramlar, fayllar, qovluqlar, skriptlər, keçidlər, əmrlər və MSI paketləri bir pəncərədə kartlar şəklində.

Portativ istifadə

Quraşdırma tələb olunmur. Bütün məlumatlar icra faylının yanında saxlanılır, buna görə proqramı USB yaddaşdan, başqa qovluqdan və ya başqa kompüterdən istifadə edə bilərsiniz.

Ardıcıl işə salma

Kart qruplarını ardıcıl, fasilələrlə və istənilən mərhələdə dayandırmaq imkanı ilə işə salın.

İdxal sehrbazı

Qovluq seçin, proqram tətbiqləri, skriptləri və qısayolları özü tapsın və kartlara yerləşdirsin.

İxrac və kolleksiyalar

Tam ehtiyat nüsxəsi yaradın və ya kolleksiyanı paylaşın: hazır alətlər dəsti yaradıb başqalarına ötürün.

Açıq məlumatlar

Bütün məlumatlar icra faylının yanında adi JSON fayllarında saxlanılır. Onları əl ilə redaktə edə bilərsiniz; proqram dəyişiklikləri özü tətbiq edəcək.

Yalnız oxuma rejimi

Qovluq yalnız oxumaq üçün əlçatandır? Kartlara baxmaq və onları işə salmaq mümkündür — proqram məhdud giriş icazələri ilə də düzgün işləyir.

Öz üslubunuza uyğunlaşdırın

15 mövzu, vurğu rəngləri və kart ikonları üçün müxtəlif üslublar.

Alətləriniz qaydasında

Bölmələr, kateqoriyalar, seçilmişlər və ani axtarış sizə lazım olanı tez tapmağa kömək edir.

Necə başlamaq

  1. ErrantLauncher-x64.exe faylını istənilən qovluğa köçürün — fləş-disk də olar.
  2. Faylı işə salın. İlk başlanğıcda yanında ErrantLauncher qovluğu yaranır — bütün məlumatlarınız orada olur.
  3. Alətlər panelindən «Redaktor»u açın və ilk kartlarınızı əlavə edin — və ya sadəcə faylları proqram pəncərəsinə sürüşdürün.
