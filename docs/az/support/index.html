Dəstək və xəta məlumatları

Burada — Errant Launcher haqqında suallarla harada müraciət etmək və xəta məlumatını necə tərtib etmək lazımdır ki, problem tez tapılıb həll olunsun.

Dəstək kanalları

Layihənin rəsmi kanalları (eyni keçidlər proqramın içində də var — «Proqram haqqında» pəncərəsi; kanallar relizin dərcindən işləyir):

Kanal Ünvan
Sənədlər Saytda sənədlər
Xəta bildirin GitHub Issues
Relizlər GitHub Releases

Yazmazdan əvvəl SSS və problemlərin həllinə baxın — bir çox suallar (SmartScreen, «Yalnız oxu», kart statusları, pəncərə ölçüsü) artıq orada izah edilib.

Xətanı necə təsvir etməli

Yaxşı məlumat üç suala cavab verir:

  1. Nə edirdiniz — addım-addım təkrarlama ardıcıllığı. Məsələn: «Redaktoru açdım → Toplu idxal → D:\Tools qovluğunu seçdim → "Skan" düyməsini vurdum».
  2. Nə gözləyirdiniz — «namizədlər siyahısı görünməli idi».
  3. Nə oldu — «proqram bağlandı» / «mesaj göründü …» — mesajın mətnini sözbəsöz yazın və ya skrinşot əlavə edin.

Məlumatlara nə əlavə etməli

Məlumat Haradan alınır
Proqram versiyası «Proqram haqqında» pəncərəsi (məs., 1.0.0-beta.1)
Windows versiyası və bitliyi Win+R → winver; arxitektura — «Parametrlər → Sistem → Haqqında»
Ekran miqyası Parametrlər → Sistem → Ekran → Miqyas (problem göstərmə ilə bağlıdırsa)
Proqram haradan işə salınıb exe faylına yol; lokal disk və ya USB
Jurnallar ErrantLauncher\logs\app.log və bootstrap.log — ErrantLauncher qovluğu exe faylının yanındadır
Təkrarlama addımları Yuxarıya baxın — nə qədər dəqiq, o qədər yaxşı
Xəta mesajının mətni Sözbəsöz və ya skrinşot

Jurnalı göndərməzdən əvvəl onu «Notepad»-da açıb məzmununu yoxlayın: jurnallarda fayl və qovluqlarınıza yollar ola bilər — açmaq istəmədiklərinizi çıxarın.

Nəyi göndərməyə gərək YOXDUR

  • Parollar, açarlar, tokenlər — proqram onları nə saxlayır, nə soruşur, amma onlar təsadüfən kopyalanmış mətnə və ya skrinşota düşə bilər.
  • Kartlarınızın tam məzmunu, əgər orada şəxsi məlumat varsa: yollar, əmrlər, keçidlər — yalnız problemlə bağlı fraqmentləri göndərin.
  • ErrantLauncher qovluğunu tamamilə, soruşulmayıbsa: konfiqurasiyanı yalnız dəstəyin tələbi ilə və məzmununu yoxladıqdan sonra ixrac edin.

Nə gözləməli

Bu, beta mərhələsində pulsuz müstəqil layihədir: cavab müddəti ilə bağlı vəd yoxdur, amma hər aydın təsvir olunmuş məlumat stabil versiyanı daha tez buraxmağa kömək edir. Relizlər səhifəsini izləyin — düzəlişlər yeni versiyalarda görünür.
