Beta version. This is a pre-release build of the app. Bugs and changes are possible. Please report issues here — it helps us ship the stable release faster.

[!NOTE] You download a single exe — no installer, no archive. One file: Windows x64 (64-bit).

Requirements

  • Windows 10 or 11, 64-bit (x64).
  • A folder with write access — the app stores its data next to the exe. Avoid Program Files and other protected locations unless you run it as administrator.
  • About 50 MB for the exe plus a little space for data.
  • On first launch, Windows SmartScreen may warn about an unknown publisher — click "More info" → "Run anyway". To be sure, compare the SHA-256 hash above (how to check: FAQ).

First launch

  1. Put the exe in a folder with write access — a flash drive works.
  2. Run it. An ErrantLauncher\ data folder appears next to it.
  3. Add cards — drag files onto the window or use the Editor. Done.
