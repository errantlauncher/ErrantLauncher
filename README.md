## About the app

Errant Launcher is a portable launch panel for Windows that keeps its
settings and data next to the executable. No installation required:
move it to a USB drive or another folder and use it on any computer.

Organize your tools into sections and categories, combine tasks into
groups, use search, and customize the look to match your style.
Your workspace stays under your control — with nothing to install.

## Key features

| Feature | Description |
|---|---|
| 9 card types | Program, Script, Folder, File, Shortcut, Command, URL / URI, MSI package, Group |
| Sections and categories | Two-level organization, custom section icons, hiding sections and categories |
| Group launch | Launches cards one after another, with pauses; the sequence can be canceled at any step |
| Mass import | Folder-scanning wizard: finds programs, scripts, installers, shortcuts, and files, and turns them into cards |
| Favorites | A separate tab for favorite cards and filters by type |
| Search and sorting | Instant search by name; sort by name, type, and launch frequency |
| Themes | 15 themes, accent colors, three card icon styles |
| System tray | Minimize to tray, "Open" / "Exit" menu |
| 6 interface languages | Russian, English, Ukrainian, Azerbaijani, Spanish, and Brazilian Portuguese |
| Drag & drop | Drop files or a link onto the window — cards appear in the current section and category |
| Availability check | Card statuses: "Available", "File missing", "Drive unavailable", and more |
| Export / import | Full backup or collection transfer without personal settings |

## Quick start

1. Copy `ErrantLauncher-x64.exe` to any folder — a USB drive
   works too.
2. Run the file. On first launch, an `ErrantLauncher` folder
   appears next to it — that's where all your data lives.
3. Open the **Editor** in the toolbar and add your first
   cards — or simply drag files into the program window.

Full instructions:
[User guide](https://errantlauncher.com/docs/guide/).

> **Note:** The executable is not code-signed, so Windows SmartScreen
> may show a warning on first launch — click **More info** →
> **Run anyway**. You can verify the file on
> [VirusTotal](https://www.virustotal.com/gui/file/3fb2a84547eb69a25f8cd271645fce9bf780af9f9a58101f4735309c02e0a168)
> or against `SHA256SUMS.txt` from the release. One engine (SecureAge)
> may report a false positive — a known reaction to unsigned,
> single-file .NET apps; all major engines report the file as clean.
