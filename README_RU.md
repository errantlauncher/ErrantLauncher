## О программе

Errant Launcher — портативная панель запуска для Windows, которая
хранит настройки и данные рядом с исполняемым файлом. Программа не
требует установки: её можно перенести на USB-накопителе или в другую
папку и использовать на другом компьютере.

Организуйте инструменты по разделам и категориям, объединяйте задачи
в группы, используйте поиск и настраивайте внешний вид под себя.
Ваше рабочее пространство остаётся под вашим контролем — без
необходимости устанавливать программу.

## Основные возможности

| Возможность | Описание |
|---|---|
| 9 типов карточек | Программа, Скрипт, Папка, Файл, Ярлык, Команда, URL/URI, MSI-пакет, Группа |
| Разделы и категории | Двухуровневая организация, собственные иконки разделов, скрытие разделов и категорий |
| Групповой запуск | Последовательный запуск карточек с паузами и отменой на любом шаге |
| Массовый импорт | Мастер сканирования папок: находит программы, скрипты, установщики, ярлыки и файлы и превращает их в карточки |
| Избранное | Отдельная вкладка с избранными карточками и фильтрами по типам |
| Поиск и сортировка | Мгновенный поиск по названию; сортировка по имени, типу и частоте запуска |
| Темы оформления | 15 тем, акцентные цвета, три стиля иконок карточек |
| Системный трей | Сворачивание в трей, меню «Открыть» / «Выход» |
| 6 языков интерфейса | Русский, английский, украинский, азербайджанский, испанский и бразильский португальский |
| Перетаскивание | Перетащите файлы или ссылку в окно — карточки появятся в текущем разделе и категории |
| Проверка доступности | Статусы карточек: «Доступно», «Файл отсутствует», «Носитель отсутствует» и другие |
| Экспорт / импорт | Полная резервная копия или передача коллекции без личных настроек |

## Быстрый старт

1. Скопируйте `ErrantLauncher-x64.exe` в любую папку — подойдёт и
   USB-накопитель.
2. Запустите файл. При первом запуске рядом появится папка
   `ErrantLauncher` — в ней хранятся все ваши данные.
3. Откройте **Редактор** на панели инструментов и добавьте первые
   карточки — или просто перетащите файлы в окно программы.

Подробная инструкция:
[Руководство пользователя](https://errantlauncher.com/ru/docs/guide/).
